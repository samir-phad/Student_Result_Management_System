&#x09;		Student Result Management System



1\. Project Objective

• The objective of this project is to develop a console-based Student Result Management System where the user can manage students and their subject marks.

&#x20;

2\. Use following concepts wherever applicable

• Used Scanner class + Switch-case to accept data from user.

• Used Lambda Expression wherever possible.

• Used Method Reference.



3\. Basic Project Flow The application starts with a menu:


&#x09;   STUDENT RESULT MANAGEMENT SYSTEM



1\. Add Student

2\. View All Students

3\. Search Student

4\. Update Student

5\. Delete Student

6\. Add/Update Marks

7\. Student Result  (Calculate total marks, percentage, grade, pass/fail)

8\. Find Topper

9\. Sort Students

10\. Exit
